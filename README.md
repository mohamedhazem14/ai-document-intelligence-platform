# 📖 Project Overview

AI Document Intelligence Platform is a Retrieval-Augmented Generation (RAG) app that lets you upload documents and then chat with them, summarize them, and turn them into quizzes. Everything runs locally: embeddings come from Sentence Transformers, vectors live in FAISS, and answers are generated by Mistral through Ollama. No cloud LLM API is involved.

---

# ✨ Features

- Upload PDF, DOCX, TXT and CSV files (several at once)
- Automatic chunking (1000 characters, 200 overlap) and embedding
- Local FAISS vector database
- Conversational Q&A with source citations and similarity scores
- Follow-up questions that take the last few chat turns into account
- Executive summary with key findings, topics and action items
- Automatic quiz: 10 multiple choice, 5 true/false, 5 short answer
- Suggested questions you can click to ask
- Export chat history (TXT / PDF) and download summary and quiz as PDF

# ⚙️ Installation

1. Install [Ollama](https://ollama.com/download) and pull the model:

   ```bash
   ollama pull mistral
   ```

2. Create an environment and install the dependencies:

   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Make sure Ollama is running, then start the app:

   ```bash
   streamlit run app.py
   ```

The first run downloads the embedding model (about 90 MB), so it needs internet once.

## 🔧 Configuration

Settings in `config.py` can be overridden with environment variables, for example:

```bash
LLM_MODEL=llama3 TOP_K=6 streamlit run app.py
```

Available: `LLM_MODEL`, `EMBEDDING_MODEL`, `CHUNK_SIZE`, `CHUNK_OVERLAP`, `TOP_K`, `DB_DIR`.

# 🚀 Usage

1. Upload one or more documents in the sidebar.
2. Click **Process Documents**.
3. Ask questions in the chat box, or click a suggested question.
4. Use the sidebar to generate a summary, a quiz, or suggested questions.
5. Export the chat or download the summary and quiz as PDF.
